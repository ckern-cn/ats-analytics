# Support

## Free community support

ATS is a free, self-hosted project. Support is best-effort and provided through
the public issue tracker:

- GitHub: <https://github.com/ckern-cn/ats-analytics/issues>
- Gitee: <https://gitee.com/ckern/ats-analytics/issues>

Please read `docs/` first and include the information requested by the bug
report template. There is no SLA and no guarantee of a response time.

## Security

Do not open a public issue for a vulnerability. Follow `SECURITY.md`.

## Donations

Donations are voluntary and do not buy support, priority, features or roadmap
influence. See `DONATE.md`.

## Paid support

The project does not currently offer paid support, hosting or consulting. Any
future commercial service would be announced separately and would not remove
features from the open-source project.
