# Internationalization

## Supported locales

| Code | Language | Default |
|---|---|---|
| `zh-CN` | 简体中文 | yes |
| `en` | English | fallback |

The default is `ATS_DEFAULT_LOCALE` (default `zh-CN`).

## Selection order

1. `?lang=<code>` query parameter (mainly for `/pv` badges),
2. `ats_lang` cookie (set by the language switcher, 1 year),
3. browser `Accept-Language` with q-values,
4. `ATS_DEFAULT_LOCALE`.

Each response sets `Content-Language` and the HTML `lang` attribute.

## Language switcher

The login page and the admin top bar link to:

```text
/lang/zh-CN?ref=/dv
/lang/en?ref=/dv
```

`/lang/<code>`:

- accepts only supported codes; other codes return 404,
- validates `ref` as a same-site path (no `//`, no `\`, no CR/LF),
- sets `ats_lang` with `Path=/`, `SameSite=Lax`, `Secure` on HTTPS,
- redirects with 303.

The switcher preserves the current path and query where possible. On the app
form validation error page it points back to `/create` or `/edit/<id>`, not the
POST endpoint.

## What is localized

- login page, dashboard, app form, errors, pagination, empty states,
- install snippets help text,
- PV badge labels,
- CSV headers and device-type values,
- unknown browser/OS labels.

Not localized: code comments, developer tool output, the hidden
`/*console.log(...)*/` tracking diagnostics, proper names such as browser names,
and raw country codes.

## Adding a language

1. Copy `ats-c/src/lang/en.h` to `ats-c/src/lang/<code>.h`.
2. Translate the values. Keep placeholders (`%s`, `%lld`) and HTML fragments
   intact.
3. Add the locale to `enum ats_locale` in `ats-c/src/i18n.h`.
4. Add the catalog, code and native name to the tables in `ats-c/src/i18n.c`.
5. Add matching rules to `ats_locale_from_code` (for example a `pt-` prefix).
6. Run:

   ```sh
   tools/ci-local.sh prod
   ```

7. Check the switcher, login page, dashboard, CSV header, PV badge and the
   language cookie.

`ats_i18n_init` logs a warning if a key has no translation in either catalog.
Missing translations fall back to English, then to an empty string.

## Translation rules

- Translate meaning, not word-for-word.
- Keep placeholders and their order; `%s` / `%lld` must stay.
- The install help string contains `<span class="mono">` and `&lt;/body&gt;`;
  keep the HTML valid.
- Do not translate the hidden tracking console messages.
- Test with `Accept-Language`, the cookie, `?lang=`, and an invalid code
  (`/lang/xx` must return 404).
